🍸 The Bartender
The Bartender es un sitio web desarrollado como proyecto para Coderhouse, enfocado en la venta de herramientas, accesorios y productos para bartenders.
Además de ofrecer productos, el sitio brinda información para quienes desean aprender sobre coctelería y crear su propia barra en casa.

------------------------------------

🚀 Tecnologías utilizadas
HTML5
CSS3
SASS
Bootstrap 5
Responsive Design
Git & GitHub

------------------------------------

📌 Funcionalidades
Página principal con navegación responsive.
Carrusel multimedia con imágenes y video.
Catálogo de productos.
Sección educativa "Aprende más".
Formulario de contacto.
Guía de compras.
Suscripción a newsletter.
Integración de redes sociales.
